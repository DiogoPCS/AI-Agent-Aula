# Stack técnica

- **Frontend:** React com TypeScript.
- **Backend:** Node.js com TypeScript.
- **Banco de dados inicial:** SQLite.
- **Compatibilidade:** navegadores modernos e dispositivos móveis.
- **Administração:** autenticação para cadastrar notícias exibidas na página inicial.

A escolha de frameworks, bibliotecas e ferramentas complementares fica aberta para a implementação, mantendo essa base como padrão inicial.
